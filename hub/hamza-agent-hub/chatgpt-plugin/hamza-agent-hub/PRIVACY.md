# Privacy policy — Hamza Agent Hub

Hamza Agent Hub is a lab MCP plugin. It processes task text, HTML/CSV you supply, and workspace artifacts on the host you run.

- No advertising trackers.
- Secrets must stay in server-side environment variables (`HAH_*`), not in the plugin ZIP.
- FreeLLMAPI keys remain on your machine / your gateway.
- Do not upload production credentials to ChatGPT chats.
- Artifact files live under the configured workspaces directory on the MCP host.

Contact the publisher via the GitHub repository for privacy questions.
